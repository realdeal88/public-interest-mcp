# Contributing

Thank you for improving public-interest infrastructure.

1. Open an issue before major changes so the scope is visible.
2. Keep every tool read-only, documented, and usable without a proprietary key where possible.
3. Add tests for changed behavior, then run `npm test` and `npm run lint`.
4. Use clear, jurisdiction-neutral language; never imply that raw public data is authoritative advice.

By contributing, you agree that your contributions are licensed under Apache-2.0.
