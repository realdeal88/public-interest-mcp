# Global Weather MCP

Global, no-key weather and air-quality tools powered by [Open-Meteo](https://open-meteo.com/). Useful for a family packing for a trip, a farmer planning work, or a logistics agent estimating conditions.

## Tools

- `find_location` — resolve a place name to coordinates.
- `get_forecast` — current conditions and up to 16 forecast days for coordinates.
- `get_air_quality` — current particulate and pollutant readings for coordinates.

Open-Meteo data is not a substitute for official warnings, safety advice, or aviation/marine forecasts.
