# Open Procurement MCP

Read and summarize public procurement data published in the [Open Contracting Data Standard (OCDS)](https://standard.open-contracting.org/). It is designed for suppliers, civil-society groups, journalists, procurement teams, and researchers.

## Tools

- `summarize_release_package` — load a public HTTPS OCDS release package and report tender, buyer, and award totals.
- `find_awards` — find awards by supplier text or minimum value in a public HTTPS OCDS release package.

Only public HTTPS URLs are accepted. The server does not submit bids or make procurement decisions. Data completeness and publication rules differ by publisher and jurisdiction.
